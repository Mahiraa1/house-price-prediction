# House Price Prediction
This is a machine learning project where I tried to predict house prices based on different features like area, number of rooms, etc.

## What I did
* Loaded and explored the dataset
* Cleaned the data (handled missing values)
* Built a model using Random Forest
* Evaluated the model using R2 score and error metrics
* Visualized results using graphs

## Tools & Libraries
* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## How to run
*Install libraries:
pip install -r requirements.txt
*Open the notebook:
jupyter notebook

## Note
The model file is not uploaded due to size limit. You can run the notebook to train the model again.
